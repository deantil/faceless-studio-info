Privacy and data handling

Last updated October 24, 2026. This notice describes the owner-operated Faceless Studio desktop workflow, rather than a public multi-user service.

Data accessed and its purpose

  • Google OAuth credentials authorize the owner's YouTube channel. They are used to authenticate requests and refresh access.
  • Channel identifiers and titles verify the destination before uploading.
  • Recent YouTube video metadata and public statistics support topic selection and basic performance reporting.
  • Scripts, primary-source text, generated audio/video, decisions and publishing results form a local audit log.

Processing and sharing

The workflow runs on the owner's computer. Language-model inference is local; the workflow does not send Google account data to an external AI inference API or use it to train a general-purpose model. Google API data is used only to operate the owner's research, publishing and performance workflow, in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

The workflow contacts Google/YouTube to retrieve information and upload videos, and primary-source websites to research stories. Published videos and their descriptions are public when the owner selects public visibility. The workflow does not sell Google data, use it for advertising targeting or send credentials to this information website.

Storage and owner controls

Credentials, source files, media and logs are stored in the owner's portable local folder. They remain under the owner's control until removed. That configured folder must be kept private. The owner can stop automatic startup using Stop-Automation.cmd, revoke access through Google Account connections, and remove locally stored credentials and records. Stopping the app or deleting local files does not remove videos already uploaded to YouTube; the owner manages those through YouTube Studio.

This website

This static website contains no account login, credential submission, advertising or application analytics. It is hosted by GitHub Pages, whose infrastructure may log visitor IP addresses for security as described in GitHub's privacy statement. Linked third-party services have their own policies.

Contact

Contact the maintainer through the project's issue tracker. Never post access tokens, OAuth client files or private channel information there.
