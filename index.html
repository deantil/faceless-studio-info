OWNER-OPERATED DESKTOP SOFTWARE

Faceless Studio

A local workflow for researching, writing, checking, producing and publishing short science explainers for the Science in Sight YouTube channel.

How it works

The owner's computer compares recent YouTube video statistics, researches primary science sources and runs an open-source language model locally. Source checks and media validation run before an upload. The owner controls the schedule and can stop the worker at any time.

Generated videos use synthetic narration and illustrated text. Source references are included in video descriptions. Automated checking does not guarantee accuracy, views or monetization.

Google access

The desktop app requests YouTube read access for research and channel verification, plus video-upload permission for publishing to the owner's channel. This page is informational: it has no sign-in form, token collection, analytics scripts or public application service.
